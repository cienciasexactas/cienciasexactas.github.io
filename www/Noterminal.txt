No terminal do VS Code, corra estes comandos:

# 1. Criar uma nova branch temporária sem histórico de commits
git checkout --orphan main-limpa

# 2. Adicionar todos os ficheiros atuais ao staging
git add .

# 3. Criar o commit inicial da nova branch
git commit -m "Site - Versão Limpa"

# 4. Eliminar a branch 'main' antiga (que tinha todo o histórico)
git branch -D main

# 5. Renomear a branch 'main-limpa' para 'main'
git branch -m main

# 6. Forçar a atualização no GitHub (substitui o histórico remoto)
git push -f origin main

Limpar e apagar o histórico local já gravado
Abra o VS Code.

Pressione a combinação de teclas Ctrl + Shift + P (ou Cmd + Shift + P no Mac) para abrir a Paleta de Comandos.

Escreva: Local History: Delete All (ou Histórico Local: Excluir Tudo).

Pressione Enter e confirme. Todos os registos da linha do tempo serão apagados imediatamente.
